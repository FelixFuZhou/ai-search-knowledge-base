## 六、判断一个新题库值不值得跟

| 检查项 | 通过 | 红旗 |
| --- | --- | --- |
| 最近活动 | 30–90 天有**内容型** commit / issue 讨论 | 只改 README 徽标，题目多年不变 |
| 可验证性 | 每个主题能指到官方文档、源码、论文或可运行案例 | 只有营销词或「用某框架即可」 |
| 版本意识 | 标注框架/协议/API 版本和迁移说明 | 仍把已废弃 API 当推荐路径 |
| 失败视角 | 有工具失败、注入、权限、评测、成本、观测问题 | 只有 happy-path demo 和定义题 |
| 社区质量 | issue/PR 有具体讨论，维护者会修正 | star 高但无维护、无讨论、无代码验证 |
| **真题成分** | 题目有**公司归属**或来自真实招聘流程 | 全是自出题 |

> 最后一行是原文档漏掉的检查项，也是它自己没通过的一项。
