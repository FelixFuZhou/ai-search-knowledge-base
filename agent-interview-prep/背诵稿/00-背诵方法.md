# 背诵方法

> 这套稿子的目标是让你**在两周内达到「不哑火」的基础水平**，而不是达到资深水平。先把地基铺满，再往上加。

## 什么能背，什么不能背

| 层 | 能不能背 | 原因 |
| --- | --- | --- |
| **L0**（30 秒） | ✅ **必须逐字背** | 这是开口速度问题。想 3 秒再开口，面试官已经在心里扣分了 |
| **L1**（2 分钟） | ✅ **背结构 + 关键句** | 选型理由是知识，背下来和想出来听不出区别 |
| **L2**（3 分钟） | ⚠️ **只能背「推演版」** | 「我踩过」不能背。被追问「当时你先怀疑什么」「数字怎么来的」两句就穿帮 |
| **L3**（2 分钟） | ✅ **背结构** | 验证方法是知识 |

**L2 的正确处理**：先背推演版（会怎么坏），需要个人经历时用降级话术——

> 「这个我没有在生产环境踩过，但我预期最容易出问题的是 ___，所以我会在上线前专门测 ___。」

**诚实降级不扣分，编造被追问穿帮扣大分。** 等主线项目跑出真实数字，再把素材槽填上。

## 怎么背（不要逐字硬背）

逐字硬背的问题是：**忘一个词就卡住整段**。正确的方法是背「骨架 + 关键句」。

每段稿子我都标了结构，比如 L0 的通用骨架是：

```
① 一句话给边界（不是定义）
② 关键区分点是什么
③ 所以工程上意味着什么
```

**练法**：
1. 先出声读 3 遍逐字稿，感受语速和停顿
2. 遮住稿子，只看骨架三点，自己说一遍
3. 录音，回听**第一句**——是定义句式就重来
4. 第二天不看稿子直接说，说不出的标记出来重点补

## 两周节奏

| 天 | 任务 | 量 |
| --- | --- | --- |
| D1–D3 | 模块 A + C 的 **L0**（20 题） | 每天 7 题，每题读 3 遍 + 复述 1 遍 |
| D4–D5 | 模块 D + E 的 **L0**（16 题） | |
| D6–D7 | 模块 B + F + G 的 **L0**（24 题） | 第 7 天把 60 题 L0 连着过一遍，计时 |
| D8–D11 | 全部 **L1**，按模块推 | 每天 15 题 |
| D12–D13 | **L2 推演版 + L3**，只做高频题（见下） | |
| D14 | 用[骨架](../系统设计/骨架.md)讲一道设计题，录音 | |

**高频题优先级**（时间不够只背这些）：


## 口语化提醒

稿子我是按**说出来**写的，不是按写出来写的。所以：

- 有口语连接词（「所以」「反过来说」「我的做法是」），**不要删掉**，它们是给你换气和思考用的
- 句子短。长句在口头表达里一定会说崩
- 有些地方我写了「（停顿）」，那是让面试官插话追问的窗口——**主动留白比一口气说完更像对话**

## 每题稿子的读法

```
⏱ 30 秒｜逐字背          ← 一字不差地背下来
🦴 骨架                  ← 忘词时靠它救场
⏱ +90 秒｜被追问时补      ← 背结构和关键句
⚠️ 别说                  ← 会被扣分的表述
```
