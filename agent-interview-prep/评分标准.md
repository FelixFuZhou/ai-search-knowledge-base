# 评分标准

## 一、单题过关判据

每题四层独立判定。**只有四层都 ≥ 及格才能标 `已掌握`。**

| 层 | 不及格 | 及格 | 优秀 |
| --- | --- | --- | --- |
| **L0**（30s） | 说不出，或超 40 秒，或第一句是教科书定义 | 30 秒内说清「是什么 + 边界」 | 第一句就给出取舍或反例，让人想追问 |
| **L1**（2min） | 只有「视情况而定」 | 说得出选型理由 | 说得出**放弃了什么**，以及什么条件下会反过来选 |
| **L2**（3min） | 想不出会怎么坏 | 能列 2–3 个失败模式 | **有自己踩过的，带具体数字**（p95、成本倍数、错误率） |
| **L3**（2min） | 「测一下」 | 说得出测什么 | 说得出**分层**测什么、线上怎么发现、以及这个指标怎么会骗人 |

### 自查红旗

出现任意一条，该题不能标 `已掌握`：

- 第一句话是定义句式（「X 是一种…」「X 指的是…」）
- 整段没有出现一个具体数字
- 说了框架名但说不出它替你解决了什么（「我用 LangGraph」→「LangGraph 解决的是状态持久化和断点续跑，我用它是因为…」）
- L2 全是「可能会」「也许会」，没有「我遇到过」
- 被问「为什么不用 X」时只会说「X 不好」，说不出 X 的适用条件

## 二、状态标记（用于题库总表）

| 标记 | 含义 | 下一步 |
| --- | --- | --- |
| `未开始` | 没碰过 | 排进 L0 |
| `L0` | 30 秒能开口 | 补 L1 |
| `L1` | 说得清取舍 | 补 L2——**多数人卡在这里** |
| `L2弱` | 只有推演的失败模式，没踩过 | 去主线项目/故障注入补素材 |
| `L2` | 有自己的踩坑素材 | 补 L3 |
| `已掌握` | 四层齐全且计时达标 | 进入间隔重复轮转 |
| `需重做` | 复习时说不出来了 | 优先级最高 |

## 三、系统设计题评分（10 分钟）

按 [骨架](系统设计/骨架.md) 的八段计分，每段 0/1/2 分，满分 16。

| 段 | 0 分 | 1 分 | 2 分 |
| --- | --- | --- | --- |
| 澄清 | 直接开始设计 | 问了问题 | 问的 3 个问题**改变了后续设计** |
| 风险分级 | 没提 | 提到有风险 | 动作分只读/可逆写/不可逆写，三档三策略 |
| 状态机 | 全交给模型 | 画了流程 | 明确划出「哪步用代码、哪步用模型」及理由 |
| 工具契约 | 只报工具名 | 有 schema | schema + RBAC + 幂等 + 超时 + 错误结构 |
| 状态与恢复 | 没提 | 提到要存 | checkpoint + 断点续跑查后端而非重放 |
| 评测 | 「测一下准确率」 | 有 golden set | 分层：工具选择 / 轨迹 / 结果，且说得出样本构成 |
| 可观测与上线 | 没提 | 提到要打日志 | trace 字段 + shadow→灰度→kill switch |
| 主动取舍 | 全程没说代价 | 被问才说 | **主动**说「初版不上 X，因为…」 |

- **< 8 分**：还在堆名词，重练骨架。
- **8–12 分**：能过一般公司的系统设计轮。
- **> 12 分**：能扛住追问。

## 四、周度自评表

每周末填。**用它判断是否过关，而不是「看完了多少题」。**

| 维度 | 0 分 | 1 分 | 2 分 | 本周 |
| --- | --- | --- | --- | --- |
| 覆盖 | 有整块题没碰过 | 全部有 L0 | 高频题有 L2 |  |
| 表达 | 超时/卡壳 | 能说完但啰嗦 | 计时内说完且第一句有信息量 |  |
| 项目 | 无进展 | 里程碑推进 | 里程碑推进且产出了新 L2 素材 |  |
| 排错 | 没注入故障 | 注入了但直接看答案 | 先写假设再排查，假设与真因有偏差并记录 |  |
| 设计题 | 没讲 | 讲了但超时 | 10 分钟内讲完且 ≥ 8 分 |  |

**总分 < 6/10**：本周不算过关。不要往前推新题，回去把「表达」和「项目」两栏补到 1 分以上——这两栏是其他三栏的前提。

## 五、面试前 72 小时检查表

- [ ] 60 题中 `未开始` + `需重做` 的数量 = 0
- [ ] 目标公司高频模块（见 [来源清单](来源清单.md) 的公司题型映射）全部 `已掌握`
- [ ] 主线项目能在 3 分钟内讲清楚：做什么、难点是什么、我怎么验证的
- [ ] 手里有 **3 个带数字的踩坑故事**，且分属不同层（工具 / 编排 / 评测）
- [ ] 9 道系统设计真题至少讲过 5 道，其中 2 道是限时冷启动
- [ ] 能说出 3 个「我不知道」的边界，并说得出打算怎么查——这一条比装懂加分
